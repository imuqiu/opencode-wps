# WPS AI 本机使用方法

适用设备：`HOME-LAPTOP`、`OFFICE-PC`、`SHOP-PC`

## 一、开始使用

1. 安装或更新完成后，保存正在编辑的文件，完全退出并重新打开一次 WPS。
2. 打开需要处理的 Writer 文档、Spreadsheets 表格或 Presentation 演示文稿。
3. 在 WPS 顶部功能区找到 **OpenCode AI** 标签页。
4. 点击 **连接状态**，确认 OpenCode 服务在线。
5. 点击 **打开面板**，在右侧 AI 对话框输入指令。

也可以点击 **打开Web**，或者在浏览器访问：

```text
http://127.0.0.1:14096
```

进行文档操作时，WPS 必须保持运行，并且当前必须有一个活动文档。

## 二、常用指令示例

Writer：

- 读取当前文档并总结主要内容。
- 检查错别字、病句和格式不一致，只列出建议，不要直接修改。
- 把一级标题统一为黑体三号，正文统一为宋体小四。
- 将当前文档另存到 `F:\WPS-AI\jobs\output`，不要覆盖原文件。

Spreadsheets：

- 分析当前表格的数据结构和异常值。
- 标记重复记录，并告诉我重复判断使用了哪些列。
- 汇总每个 Sheet 的关键数字，生成一个新的汇总 Sheet。
- 根据当前数据生成图表，修改前先说明计划。

Presentation：

- 总结当前演示文稿的结构并提出精简建议。
- 新增一页结论页，不要修改已有页面。
- 统一标题字体、字号和颜色。
- 根据当前工作簿生成一份汇报 PPT 初稿。

## 三、权限与文件安全

本方案默认使用 `manual` 权限模式。出现授权提示时：

1. 检查工具名称和目标文件路径。
2. 确认目标属于当前文档或 `WPS-AI` 工作区。
3. 对删除、覆盖、批量修改操作保持谨慎。
4. 重要文件优先要求“另存为”，不要直接覆盖原件。

WPS 同步文件夹会把新增、修改和删除同步到其他电脑。它能保持三台电脑内容一致，但不能替代独立备份。批量操作前应保留原文件或建立副本。

## 四、启动与健康检查

Launcher 会随用户登录自动运行，正常情况下不需要手动启动。

无法连接时运行：

```powershell
& 'F:\WPS-AI\scripts\health-check.cmd'
```

全部项目显示 `OK` 后，重新打开 WPS 的 OpenCode AI 面板。

需要修复安装时运行：

```powershell
& 'F:\WPS-AI\scripts\repair.cmd'
```

需要检查 MCP 时运行：

```powershell
opencode mcp list --pure
```

正常结果应包含 `wps-office connected`。

## 五、升级方法

只有 `HOME-LAPTOP` 负责发布稳定版本。办公室和店铺电脑看到 WPS 同步完成后，按需运行：

```powershell
& '<本机WPS-AI路径>\scripts\update.cmd'
```

升级顺序固定为：家里笔记本先验证，办公室电脑第二，店铺电脑最后。不要让店铺电脑直接追踪 GitHub 最新提交。

## 六、常见问题

### WPS 中没有 OpenCode AI 标签页

完全退出所有 WPS 窗口后重新打开。如果仍然没有，运行 `repair.cmd`，完成后再次重启 WPS。

### 显示服务未连接

先运行 `health-check.cmd`。如果 Launcher 正常但 OpenCode 没有运行，可重新打开 WPS 面板；也可以在浏览器打开 `http://127.0.0.1:14096`。

### AI 找不到文件

确认文件已经由 WPS 同步完整下载到本机，而不是仅存在于云端。三台电脑的盘符可以不同，应使用当前电脑的实际本地路径。

### 操作似乎卡住

检查侧边栏是否正在等待权限确认。看到橙色等待提示时，核对操作后选择允许或拒绝。
